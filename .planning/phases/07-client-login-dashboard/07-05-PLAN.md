## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Supabase row to DOM | Row text is marketer-edited but treated as untrusted when rendering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-13 | Tampering | SDK served from a CDN | mitigate | Vendored, `script-src 'self'` from 07-07, no remote host allowed by check-portability |

| T-07-25 | Information disclosure | Account enumeration at sign-in | mitigate | One message for all credential failures |
