# 07.1 Research notes: what makes a client dashboard useful (2026-11-22)

A quick web scan for the user. Most sources are vendor blogs, so treat them as practitioner advice; where they agree, the advice is consistent.

## Findings

1. **Answer the main question in about 5 seconds.** Show a few key numbers at the top, using size and placement, not a wall of charts. Too many KPIs leads to "dashboard fatigue". (Sisense, Qlik, TechTarget)
2. **Show the actions a local business cares about.** For a Google Business Profile those are phone calls, direction requests and website clicks; impressions only show visibility. Pick the few that match each client's goal (a café wants visits, a plumber wants calls) instead of showing everything. (AgencyAnalytics, SEJ, ReportingNinja)
3. **Show change, not just totals.** Compare with last month and flag drops early, before the client asks. (AgencyAnalytics local SEO guides)
4. **Use plain language for non-technical owners.** Use short labels, round the numbers, add icons beside key metrics, and give each number a sentence of context. (DataCamp, insightsoftware, Toptal)
5. **Put the detail one step down.** Keep the first view simple and move history and detail lower, or behind "see more". (Toptal, DataCamp, CACM)
6. **A portal is also where work happens.** Agency portals bundle deliverables, approvals, files or reports, messaging and billing in one place, which cuts back-and-forth email. For a small client list, a simple dashboard is enough when reporting is the main touchpoint. (Vendasta, Assembly, AgencyAnalytics, Zite)

## Fit with this project

- There is no server of our own and no API integrations yet, so the marketer types the numbers monthly in Supabase's table editor (the same place dashboards are edited today). Pulling data automatically from the Google Business Profile or ad accounts needs server-side code and OAuth, so it is future work (it could fit Phase 8's Edge Functions).
- Every field stays per client, under the existing RLS (a client can read only their own row).

## Candidate features

- At a glance: 3 numbers for this month (for example calls, direction requests, website visits), each with an arrow and "up 12% on last month" in words.
- A note from Sam: what we did, what happened, what's next (2-4 short lines).
- Waiting on you: approvals and things needed from the client (an extension of today's "next steps").
- Done this month: a list of the work delivered.
- Coming up: the next check-in and the renewal or invoice date.
- Contact: a button to call, email or book a chat.
- Candidates for Growth only, shown but locked for Local Basics: a 6-month trend chart, the content calendar for the next 2 weeks, ad results (spend, clicks, results), and a monthly report archive.
