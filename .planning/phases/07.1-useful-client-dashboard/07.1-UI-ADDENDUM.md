# Phase 07.1 UI addendum: dashboard sections and the locked state

This extends `07-UI-SPEC.md` (which inherits 01 and 02 UI-SPECs). Everything not stated here is unchanged: tokens, type scale, spacing, the "no flash of protected UI" rule, the loading, empty, failure and signed-out states, header, footer and sign-out. Where this conflicts with 07.1-CONTEXT.md, CONTEXT wins. Plans 07.1-05 (tests), 07.1-06 and 07.1-07 (build) treat the copy below as exact strings.

## Rules carried over (binding)

- dashboard.html stays empty of client content. Every heading below is created by `js/dashboard.js` after a verified row read (`check-auth dashboard-page` bans them from the static file).
- All values go in with `textContent`. No `innerHTML`, no `style` attribute anywhere (CSP `style-src 'self'`). Visual properties live in `css/styles.css` classes; JS sets only `class`, `href`, `rel`, `aria-*`, `role` and SVG geometry attributes.
- New CSS uses existing tokens only (`--color-*`, `--space-*`, `--fs-*`, `--radius-*`, `--shadow-card*`). No hex outside `:root`, no new tokens. Budget for additions: about 6KB (styles.css is 66.8KB; Home loads it too).
- Cards are white `.card.card--white` on the single tint band (`section.section--tint`), static (no hover lift), h2 per card at the existing `.dash__grid .card h2` style.
- Dates: parse `YYYY-MM-DD` by splitting into `new Date(y, m-1, d)`; format with `toLocaleDateString("en-GB", ...)`. Numbers with `Intl.NumberFormat("en-GB", {maximumFractionDigits: 1})`; money with `Intl.NumberFormat("en-GB", {style: "currency", currency: "GBP"})`.

## 1. At a glance (DASH-01)

- Above the tiles, a Label-style line: `Figures for {Month YYYY}` (for example "Figures for October 2026"), from `report_month`.
- Three tiles in a row (stack on phone), one per KPI with a non-empty label: label (Label type, ink-soft), the number (Fraunces, `--fs-heading`, ink), and the change line (Body small): an `aria-hidden="true"` arrow span (↑, ↓ or →) followed by the words.
- Change wording, comparing the report-month row with the row whose month is exactly one month earlier (matched by month string, never by array position):

| Case | Text | Arrow |
|------|------|-------|
| this month missing or not a finite number | No figure for this month yet | none |
| last month missing or not a number | First month we’ve tracked this | none |
| equal (including both 0) | Same as last month | → |
| last month 0, this month more | Up from none last month | ↑ |
| last month under 10 | Up {n} on last month / Down {n} on last month | ↑ / ↓ |
| otherwise, rounded percent is 0 | About the same as last month | → |
| otherwise | Up {p}% on last month / Down {p}% on last month | ↑ / ↓ |

  Down is styled neutrally (ink-soft), never error red.
- Empty states: `report_month` null, or no labels set: the card shows only the heading and "Your first numbers will appear here after your first monthly report." A labelled KPI with no figure shows "–" as the number and "No figure for this month yet".

## 2. Waiting on you (DASH-02)

- `dashboard_items` with `kind = 'waiting'`, ordered by `sort_order` then `item_date` (nulls last). Each item: title (strong), detail (span), and if `item_date` is set a `.dash__due` line `By {weekday day month}` (for example "By Friday 27 November").
- Empty: "Nothing waiting on you right now."

## 3. Done this month (DASH-03)

- `kind = 'done'` whose `item_date` falls inside the report month. Items with no date or another month are not shown. Each: title, and a small date `{day month}` (for example "8 October"). Tick glyph optional and `aria-hidden`.
- Empty: "Nothing marked as done for {Month} yet." With no `report_month`: "Nothing marked as done yet."

## 4. Coming up (DASH-04, DASH-05)

- A `dl`: "Next check-in" → `{weekday day month year}` from `next_check_in` (for example "Friday 4 December 2026"), followed by the `check_in` text when present, in ink-soft; "Renewal" → `{day month year}` from `renewal_on`. Missing date: "To be arranged".
- Contact row (site-wide constants, same as the footer, no third party):
  - `Call 01632 960 123` → `tel:+441632960123` (`btn btn--primary`)
  - `Email Sam` → `mailto:hello@samwhitlock.example` (`btn btn--ghost`)
  - `Book a chat` → `mailto:hello@samwhitlock.example?subject=Book%20a%20chat` (`link-cta`)
  All 44px targets (existing rules). Wrap on phone.

## 5. Your plan (AUTH-04)

- Unchanged list (Plan, What’s included, no Check-in row because it moved to Coming up) plus a first row "Tier" → "Local Basics" or "Growth" (`plan_tier`; anything other than `growth` reads "Local Basics").

## 6-9. Growth cards (DASH-07, DASH-08)

Decision rule: render Growth content only when `row.plan_tier === "growth"` exactly. Anything else (missing, unknown, error) renders the locked state. The locked state never fetches Growth tables.

### Locked state (basics)

- Same card, heading as in the table, then a pill `Growth plan` (class `dash__badge`: Label type, ink on `--color-tint`, `--radius-pill`), then one sentence, then a `link-cta` "Ask about Growth" → `mailto:hello@samwhitlock.example?subject=Growth%20plan`.
- Sentences (exact):
  - Your last 6 months: "See the last 6 months of your numbers as a simple chart."
  - Posts for the next 2 weeks: "See every post planned for the next 2 weeks."
  - Ad results: "See what your ads cost and what they brought in."
  - Monthly reports: "Open every monthly report in one place."
- Decoration: a purely CSS shape block (`dash__ghost`, `aria-hidden="true"`, a few bars drawn with `linear-gradient` from `--color-line` / `--color-tint`), constant, no numbers, no SVG, no real data. Not a disabled control.

### Growth content

- Your last 6 months: three small charts (one per labelled KPI), each an inline `svg.dash-chart` with `viewBox="0 0 240 90"`, `role="img"` and an `aria-label` like "Sample: calls, last 6 months: May 31, Jun 35, Jul 33, Aug 38, Sep 40, Oct 45". Points are the months from report month minus 5 to report month, x by month position, gaps left as gaps, y from 0 to max with 10% headroom; a flat series is a flat line; a single point is a dot. Classes `dash-chart__line` (blue stroke 2.5, no fill), `dash-chart__dot` (blue fill). Beside each chart, real text: the label, the latest value, and the first and last month names. Fewer than 2 months with figures: "Your trend will appear after your second monthly report." No animation.
- Posts for the next 2 weeks: posts with `post_on` from today to today + 14 (local date, also filtered in the page), ordered by date: `{weekday day month}` · channel · title · status. Empty: "Nothing planned for the next 2 weeks."
- Ad results: rows for the report month, one per campaign: campaign, "Spent {£}", "{n} clicks", "{n} {results_label}". Empty: "No ad results for {Month} yet."
- Monthly reports: up to 12 links, newest first, text `{title}`, `href` only if the url starts with `https://` (else the title as plain text with "(link not available)"), `rel="noopener noreferrer"`. Empty: "No reports yet."
- Failure of any Growth request: inside that card only, "I couldn’t load this section." and a "Try again" button that refetches only Growth data. Never shown as locked; other cards unaffected.
