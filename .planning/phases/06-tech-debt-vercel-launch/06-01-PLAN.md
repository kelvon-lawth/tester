## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo checkout to public _site | Everything copied into _site becomes public on the internet |
| build environment to deployed HTML | An environment variable value is written into a served page |
| local working tree to GitHub | Each push publishes committed files; the tree holds untracked .claude/ and the Keychain holds a token |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information disclosure | tools/build-site.sh | mitigate | Allowlist copy, so a new repo file cannot ship by default; tools/check-deploy.js fails on any extra file in _site (OPS-01) |
| T-06-02 | Information disclosure | css/styles.css in _site | mitigate | .sg-* rules move to css/styleguide.css; the build and both guards fail on any .sg- in deployed or main CSS (D-05) |
| T-06-03 | Tampering | build stamp in tools/build-site.sh | mitigate | The SHA value is filtered with tr -cd to letters and digits before it enters the HTML comment; check-deploy tests a hostile value |
| T-06-04 | Information disclosure | git push in Task 3 | mitigate | Paths staged by name, never git add -A; check that .claude/ is absent from pushed paths; history scan for GitHub token shapes (earlier tokens were pasted in chat) |
| T-06-05 | Denial of service | tools/build-site.sh | mitigate | set -eu plus explicit fail checks, so a broken build stops the deploy and the previous deployment keeps serving |
| T-06-06 | Elevation of privilege | pages.yml running a repo script with pages:write and id-token:write | accept | The script comes from the same repo and commit as the workflow, so it adds no new trust; the workflow is removed in Plan 06-02 |
| T-06-07 | Information disclosure | commit SHA in deployed HTML comment | accept | A commit hash exposes no secret and serves only as a redeploy marker; low value to an attacker |

No package installs in this plan, so no supply-chain entry applies. No high-severity threat is left open.
