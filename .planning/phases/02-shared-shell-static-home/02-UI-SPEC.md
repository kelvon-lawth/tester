### Sticky mobile CTA (SHL-04), D-09 — Home only
`<a class="btn btn--primary sticky-cta" href="contact.html">Let's talk</a>` as the last child of `<body>` on `index.html` only.

- Shape (decided): full-width button inside the gutters, not a full-bleed bar. `position: fixed; inset-inline: var(--space-md); inset-block-end: calc(var(--space-md) + env(safe-area-inset-bottom, 0px)); z-index: 5; box-shadow: var(--shadow-card);` `min-block-size: 44px` (inherits `.btn`, pill radius).
- Visible only below 640px (`display: none` at 640px+).
- No-JS / pre-JS: shown always on phones (default CSS state is visible). `js/main.js` (which already adds `js` to `<html>`) enables the enhancement: `.js .sticky-cta` starts hidden (`transform: translateY(calc(100% + var(--space-xl))); opacity: 0; visibility: hidden;`) and `.js .sticky-cta.is-visible` shows it (`transform: none; opacity: 1; visibility: visible`). Transition: `transform` and `opacity` over `--dur-base` `--ease-out`; `visibility` flips with the same duration so a hidden CTA is not focusable. Reduced motion collapses transitions (existing global rule).
- IntersectionObserver logic (classic script, feature-detected; if `IntersectionObserver` is missing, do nothing so it stays visible):
  - Observe `#hero-cta` (hero button row). "Past hero" = not intersecting AND `boundingClientRect.bottom < 0` (scrolled beyond it, not merely below the fold).
  - Observe `.cta-band` and `footer.site-footer` with `threshold: 0`. "Blocked" = either is intersecting.
  - Visible = pastHero AND NOT blocked. Recompute on every callback. Default `rootMargin: "0px"`.
- `html` gets `scroll-padding-block-end: var(--sticky-clearance)` below 640px so keyboard focus is never hidden behind the bar (WCAG 2.4.11).
- Focus ring uses the standard blue ring (white page behind). No close button, no dismiss, no animation beyond the slide/fade.
